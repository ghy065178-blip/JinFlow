## 下载

本次在原 `v2.0.0` 页面更新 Apple Silicon、Intel Mac、Windows x86_64 和 Windows ARM64 的安装包。macOS 可用 DMG 或 ZIP，Windows 可用 Setup.exe 或 ZIP。发布资产附有 SHA-256 校验和、更新清单和升级助手。

本页记录相较最初发布的 2.0.0 的变化。1.3.0 已有玻璃质感、三种主题和北京时间，本次在这些基础上调整了视觉与操作体验。

## 更新

- JinFlow 采用液态玻璃参考稿的极光色、圆角面板和顶部高光。品牌栏、任务栏、五张状态卡、左栏表单和右栏终端沿用原工作顺序。支持黑色、白色和跟随系统。
- 顶栏 Logo 从 1,024 × 1,024 像素母图按显示缩放选择抗锯齿资源，macOS 和 Windows 系统图标也已重新导出。

## 新增

- 拖动左栏与终端之间的分隔线可扩大或缩小表单区域。
- 默认在启动时后台检查更新。发现适用的新版本时，顶部显示「更新」。打开面板并确认后才开始下载和安装。面板显示下载、校验、安装、成功或失败。
- Windows 可用 F11 切换全屏，按 Esc 退出全屏。

## 修改与修复

- 加快左栏鼠标滚轮响应，保留触控板的细粒度输入和触摸拖动，减少连续输入触发的重复绘制。
- 档案下拉框和操作按钮分行，「删除」位于「重命名」右侧。按钮等宽排布，避免较窄窗口中被下拉框挤出。
- Windows 改为合并连续的窗口尺寸变化，并在尺寸稳定后刷新状态卡与任务标签。提示层使用常规绘制流程，减少缩放、最大化、还原及切换全屏期间的同步重绘。
- Windows 退出旧程序后完成替换并报告安装结果。macOS 更新在启动请求失败时恢复原安装。
- 修订 2 补齐 macOS 暂存启动。源码或只读位置发起更新时保留完整 `.app`，已重命名的 `.app` 可原位更新。

## 兼容性

本次为 JinFlow **2.0.0 修订 2**，安装包构建号为 `2.0.0.2`。原 2.0.0 用户可从「帮助 → 检查更新与升级」进入更新面板。旧版 macOS 从 DMG 或只读目录运行时，可下载新版 DMG，把应用拖入「应用程序」覆盖安装。报名信息、档案、任务和设置继续使用本机数据目录。

## 验证

四种原生构建均运行回归测试及应用自检。Windows 验证包含普通窗口缩放、最大化、还原、全屏切换、安装与卸载，以及更新成功和回滚。macOS 验证包含 ZIP 解压和 DMG 挂载后的签名及 HTTPS 检查。
