# 原功能 → 桌面版功能对照

「保持原有内置功能、业务逻辑和数据处理结果不变」的逐项核对表。✅ 等价保留；🔄 实现方式升级但效果等价；➕ 新增；⚠️ 有意差异（隐私要求）。

> **界面一致性**：主窗口已重排为与 `control_panel.html` 完全相同的深色单页布局，
> 全部文案、按钮、复选框、状态卡、交互行为与配色逐项对齐，详见
> `docs/UI_PARITY.md`，并由 `tests/test_ui_parity.py` 静态回归。
> 原先的「四个标签页」已取消，附加能力改由菜单与弹窗提供，不再占用主界面。

## 四、有意差异汇总

1. **移除内置活动 token**：旧版把某次真实活动的表单 token 硬编码在 `DEFAULT_TOKEN` 中（此处不复述其值）。桌面版不内置任何活动链接，首次需用户填写；之后复用本地「上次链接」，与旧版「回车=上次链接」的实际体验一致。
2. **多开任务由子进程改为独立线程**：提交是 I/O 密集（urllib 会释放 GIL），线程足以并行；隔离由独立配置目录 + 独立上下文保证，取消 stdout 抓取后更可靠。
3. **自动应答不再解析终端提示**：旧版通过 13 条正则匹配 `input()` 提示语后写 stdin；新版在缺项时直接由 GUI 弹窗或配置值应答，结果一致且不会因文案变化失效。
4. **可选 CLI 保留**：`python -m jsj_desktop --cli` 提供与旧版相同的终端菜单，仅作自动化/无障碍兜底，不是主交互方式。
5. **2.0.0 只做增量新增**：主题令牌、主题设置、方案 B 图标资源和北京时间时区辅助函数均为增量能力；`core/` 的提交语义、数据格式和主窗口区域保持不变，原有等价性测试继续执行。
6. **旧冻结包无法凭空获得应用内更新**：1.0.x 已发布的二进制不含更新代码，因此提供 Release 资产 `JinFlow-Upgrade-Helper.py`（`tools/upgrade_legacy.py`）作为一次性桥接；这是分发事实，不是功能缺失。
